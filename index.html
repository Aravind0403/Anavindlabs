Clairvoyant: Predictive Request Scheduler

Go sidecar proxy sitting before upstream backends (Ollama, llama.cpp) without backend modification. Evaluates a 19-feature XGBoost model exported to ONNX to infer output token lengths at 0.029ms P99 for Shortest-Job-First dispatch.

Benchmark Results (Published in arXiv:2606.07248)
P50 Latency (GCP L4, trace replay) -83.6%
P50 Latency (RTX 4090, burst) -70% to -76%
Pairwise Ranking (LMSYS-Chat-1M) 95.1%
Empirical Finding & Limitation

Curated instruction datasets (Alpaca-style) proved completely unusable as training data due to GPT-imposed brevity bias. Real-world multi-turn conversational traces (ShareGPT, LMSYS) were required to achieve valid ranking.

Kube-Sentinel: Native K8s GPU Scheduler

Native Kubernetes scheduler plugin implementing PreScore, Score, Reserve, Unreserve, PreBind, and PostBind hooks in Go, backed by a Python gRPC telemetry daemon with circuit-breaker resilience.

Explicit Provenance Caveat

The 46.3% GPU cost reduction ($64.44/hr vs $120/hr) is derived entirely from an offline trace-replay simulation on Alibaba 2018 cluster logs across 32 nodes. It is a modeled projection, not a measured production saving.

Disconfirmed Result Disclosed Vast.ai A100 + RTX 3090

HeteroDisagg: Asymmetric Hardware Serving

Addresses vLLM/SGLang's assumption of uniform GPU clusters by assigning high-TFLOPS GPUs to prefill and high-bandwidth/$ GPUs to decode, bridged by HeteroKVConnector asymmetric TP resharding and in-flight FP8 quantization.

Measured Accuracy & Wire Transfer
Output Cosine Similarity (vs FP16) 99.1% - 99.7%
Perplexity Shift (Llama-3-8B) ≤ 0.0018
Wire Payload Reduction 2.0x (FP8)
Documented Disconfirmed Result

The isolated FP8 GPU quantization kernel is slower than uncompressed FP16 (+11ms to +32ms overhead depending on concurrency). The performance win is strictly wire-bandwidth reduction across network-constrained links, not compute speed.
