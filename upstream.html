vLLM PR #51574 Co-Authored Status: Open

Preempted Requests Starvation & Re-Admission in PriorityRequestQueue

Origin & Root Cause: I filed the initial bug report (vLLM issue #41951), identifying that when vLLM's v1 engine experiences memory pressure and preempts in-flight requests, those preempted requests lose re-admission priority in the PriorityRequestQueue, causing indefinite starvation under continuous ingress traffic.

Fix Evolution: I authored two successive patches: PR #41952 (stale) and PR #56843 (which introduced a bounded starvation cap). The changes and regression test suite were subsequently cherry-picked into the consolidated PR #51574, where I hold co-authorship credit.

Impact: Prevents catastrophic latency tail inflation (P99) under sustained memory saturation by enforcing deterministic starvation bounds.

vLLM PR #56964 Author: Aravind Status: Open

Marlin Quantized Backend Crash with Unquantized Draft Models

Root Cause: When running speculative decoding where the target model is Marlin-quantized (FP8/INT4) but the draft model contains unquantized layers, vLLM threw an unhandled execution exception because the Marlin backend failed to execute non-quantized tensor operations.

Architectural Fix: Implemented a dynamic fallback check in the speculative decoding model loader, gracefully defaulting unquantized draft layers to the auto backend execution path without degrading target kernel speed.

Impact: Enables heterogeneous quantization regimes in speculative decoding setups without runtime engine termination.

SGLang PR #39623 Author: Aravind Status: Open

Unbounded Memory Growth in Prefill/Decode Disaggregation via Orphaned ZMQ Rooms

Root Cause: In SGLang's disaggregated prefill/decode architecture, ZeroMQ bootstrap rooms are allocated to coordinate inter-node tensor transfer. Under network partitions or abrupt client disconnects, room references were never garbage-collected, leading to linear memory growth and eventual host OOM.

Architectural Fix: Added an active O(1) min-heap TTL (Time-To-Live) sweeper thread that periodically cleans expired handshake tokens and evicts orphaned room states.

Impact: Stabilizes long-running disaggregated cluster instances against client dropouts and network jitter.

SGLang PR #39741 Author: Aravind Status: Open

Qwen3.5 GDN Hybrid Model Crash Under Marlin Tile Divisibility

Root Cause: Attempting to load Qwen3.5 GDN hybrid architecture models under Marlin quantization resulted in silent tile divisibility violations, causing CUDA illegal memory access errors during tensor layout initialization.

Architectural Fix: Added pre-flight dimension validation checking tile-divisibility constraints prior to kernel invocation, triggering safe fallback to compatible kernel variants when non-standard dimensions are encountered.

Impact: Prevents silent GPU crashes when loading non-standard hybrid recurrent/transformer weights.

SGLang PR #37067 Author: Aravind Status: Open

Refactoring RadixCache.total_size() from O(N) to O(1)

Code Change: Refactored the internal radix tree size accounting in RadixCache to maintain an incremental token count during insertion and eviction, eliminating recursive tree traversals on metric polling.

Disclosed Scope Clarification

Maintainer-confirmed code-hygiene improvement, not a hot-path performance fix. Because total_size() is typically invoked for telemetry and logging rather than inside the critical per-token decode loop, this PR improves algorithmic cleanliness and code maintenance rather than raw latency.
